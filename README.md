## อัปเดตจาก 1.0.1 เป็น 1.0.2

อัปโหลดไฟล์และโฟลเดอร์ภายในชุดนี้ทับ GitHub repository เดิม โดยให้ `package.json` และ `vercel.json` อยู่ระดับบนสุด แล้ว Commit; Vercel ที่เชื่อม GitHub จะสร้าง Deployment ใหม่

**Apps Script, Google Sheet และ Environment Variables ใช้ชุดเดิมได้ ไม่ต้องรัน setupSystem หรือเผยแพร่ Apps Script ใหม่** โค้ด Backend ไม่ได้เปลี่ยนในรุ่นนี้ และข้อมูลเดิมไม่ถูกล้าง

เมนูใหม่ **จัดการข้อมูลเงินทุน** อยู่ใต้ ADMINISTRATION สำหรับบัญชี ADMIN มีปุ่มลัด **แก้ไขข้อมูลเงินทุน** บนหน้ารายงานและหน้าวิเคราะห์ด้วย

- คณะใหม่: เพิ่มคณะใหม่และกรอกเงินทุน → บันทึกชื่อคณะ → แบบฟอร์มขั้นตอน 2 เลือกคณะใหม่ให้อัตโนมัติ → กรอกปี จำนวนอาจารย์ เงินทุน และคะแนน → บันทึก
- แก้รายการเดิม: เลือกปี/คณะ → กดแก้ไขที่ต้นแถว → เปลี่ยนจำนวนอาจารย์ ทุนสถาบันฯ ทุนวิจัยภายนอก และผลคะแนน → บันทึก
- คณะที่มีอยู่แล้วแต่ยังไม่มีข้อมูลในปีนั้น: กดเพิ่มข้อมูลแล้วเลือกคณะและปี
- ผลรวมและค่าเฉลี่ยต่อหัวคำนวณจากเงินทุนและจำนวนอาจารย์/FTE ส่วนคะแนนเลือกกำหนดเอง 0–5 หรือใช้เกณฑ์ AUTO ที่ Admin ตั้งไว้
- หากยกเลิกขั้นตอนกรอกเงินทุนหลังบันทึกชื่อคณะ คณะจะยังคงอยู่ และกลับมาเพิ่มเงินทุนได้ภายหลัง
- ทุกหน้าข้อมูลรวมหน้าจัดการใหม่พิมพ์/บันทึก PDF และดาวน์โหลด CSV ตามตัวกรองได้

Teacher ยังคงเพิ่มและแก้ไขเงินทุนผ่านเมนูข้อมูลเงินทุนได้ แต่ลบหรือจัดการฐานคณะไม่ได้; Owner และไฟล์ Preview เปิดดูและส่งออกเท่านั้น

## สิ่งที่มีในเวอร์ชันนี้

- ฟอนต์หลัก Sukhumvit Set สำหรับเครื่องที่มีฟอนต์นี้ และ Noto Sans Thai แบบ variable ที่แนบไว้เป็นฟอนต์สำรอง โหลดจากเว็บเดียวกัน ไม่ต้องพึ่งบริการฟอนต์ภายนอก
- ข้อความหลักและตาราง 16px, ข้อความประกอบอย่างน้อย 14px; ใช้ rem เพื่อรองรับการปรับขนาดข้อความของเบราว์เซอร์
- มือถือใช้การ์ดหนึ่งคอลัมน์ iPad/จอขนาดกลางปรับเมนูเป็นแถบเลื่อนพร้อมชื่อเมนู จอใหญ่ใช้ Sidebar; ตารางและกราฟกว้างเลื่อนภายในกล่องได้ และแบบฟอร์มเลื่อนในหน้าต่างได้


- Dashboard: เงินทุนรวม ทุนภายใน ทุนภายนอก FTE ค่าเฉลี่ยต่อ FTE คะแนนเฉลี่ย และแนวโน้มรายปี
- ตารางข้อมูลทุน ค้นหาและกรองคณะ/ปี เพิ่มและแก้ไขผ่าน Popup คำนวณยอดรวมทันที
- เปรียบเทียบรายปีครบทุกคณะ แสดงส่วนต่างเงินและร้อยละ รวมถึงข้อมูลที่ไม่มีในปีใดปีหนึ่ง
- วิเคราะห์รายคณะ และรายงานที่กรองก่อนส่งออก Excel `.xlsx` / CSV / พิมพ์เป็น PDF
- Admin จัดการคณะ บัญชีผู้ใช้ รีเซ็ตรหัสผ่าน เกณฑ์คะแนน ดูประวัติ และกู้คืนข้อมูลทุนที่ลบ
- Google Sheet เก็บข้อมูลทุน คณะ ผู้ใช้ เซสชัน เกณฑ์ ตั้งค่า และ AuditLog ภายในไฟล์เดียว
- Backend ตรวจสิทธิ์จริงทุกคำขอ Teacher เรียก API ลบเองก็จะถูกปฏิเสธ
- กันคณะ–ปีซ้ำ กันข้อมูลติดลบ ตรวจ revision เพื่อกันการบันทึกทับข้อมูลที่เปลี่ยนแล้ว
- เซสชันแบบ HttpOnly cookie มีอายุ 8 ชั่วโมง เก็บเฉพาะ hash ของ token ใน Sheet
- ข้อมูลตัวอย่างไม่ถูกใส่ในไฟล์เว็บที่ Deploy และรหัสผ่านไม่ได้ถูกฝังใน JavaScript หน้าเว็บ

## ข้อมูลตั้งต้นและวิธีคำนวณ

| ปี | จำนวนรายการ | FTE รวม | ทุนภายใน | ทุนภายนอก | เงินทุนรวม |
|---|---:|---:|---:|---:|---:|
| 2567 | 14 | 456 | 2,935,042.00 | 22,406,455.63 | 25,341,497.63 |
| 2568 | 14 | 437 | 1,670,393.00 | 49,715,678.33 | 51,386,071.33 |

จำนวนอาจารย์รองรับทศนิยม เช่น 78.5 ตามไฟล์ต้นทาง โดยใช้คำว่า “คน/FTE” จนกว่าจะยืนยันนิยามจากหน่วยงาน

เงินทุนรวม = ทุนภายใน + ทุนภายนอก / บาทต่อ FTE = เงินทุนรวม ÷ FTE / คะแนนภาพรวม = ค่าเฉลี่ยเลขคณิตรายคณะ ไม่ถ่วงน้ำหนัก

คะแนนตั้งต้นทั้งหมดเก็บตาม Excel ไม่เดาสูตรประเมิน เมื่อมีเกณฑ์อย่างเป็นทางการ Admin กำหนดเป้าหมายเงินทุนต่อ FTE แยกคณะและปีได้ และเลือกรายการให้คำนวณอัตโนมัติด้วย `min(5, บาทต่อ FTE / เป้าหมาย × 5)` สูตรนี้เป็นตัวเลือกของระบบ ต้องตรวจว่าใช้ตรงกับเกณฑ์หน่วยงานก่อนเปิดใช้

การตั้งค่าเริ่มต้นสร้างชีตฐานข้อมูลเพิ่มเติม ไม่ลบชีต `ปี 2567` และ `ปี 2568` และนำเข้าข้อมูลตั้งต้นเฉพาะตอน `FundingData` ว่างทั้งชีต การรันซ้ำไม่เขียนทับข้อมูลใช้งานจริง

## ดูหน้าตาในเครื่อง

ต้องมี Node.js 20 ขึ้นไป โดยไม่ต้องติดตั้ง dependency ของเว็บ

```bash
npm run preview
```

เปิด `http://localhost:4173/?demo=1` เป็นตัวอย่างสำหรับดูหน้าตาเท่านั้น ไม่ใช่การเชื่อมฐานข้อมูลจริง

```bash
npm test
npm run build
```

`npm test` ทดสอบ API กับตัวจำลองบริการ Google Sheets และตรวจตัวกลาง Vercel ไม่มีการเขียน Google Sheet จริง

`npm run build` สร้าง `dist/` และตัดชุดข้อมูลตัวอย่างออก การเปิด `?demo=1` บนเว็บ Production จะไม่มีข้อมูลตัวอย่างให้โหลด

ทดสอบ UI เพิ่มเติมได้ด้วย `node tests/ui-smoke.mjs` เมื่อมี Playwright และ Chromium พร้อม และเปิด preview server ไว้

## ขอบเขตการส่งมอบ

ชุดนี้เป็นโค้ดพร้อมติดตั้ง ไม่ได้เผยแพร่ลงบัญชี Vercel หรือ Apps Script ของคุณ และยังไม่ได้ทดสอบกับ Google Sheet สด เพราะไม่มี Web App URL /exec ที่ Deploy แล้วหรือการเข้าถึงบัญชีของคุณ

## การเปลี่ยนจากเวอร์ชัน Cloudflare

ใช้ `api/dispatch.js` เป็น Vercel Function และ `server/gateway.js` เป็น API gateway แทนโฟลเดอร์ functions ของ Cloudflare โดยมี `vercel.json` กำหนด Build และ security headers ให้แล้ว

หากตั้ง Apps Script รุ่น 1.0.0 สำเร็จอยู่แล้ว ใช้ URL /exec และ API_SHARED_SECRET เดิมได้ ไม่จำเป็นต้องรัน setup ใหม่ ข้อมูลและสิทธิ์เดิมคงอยู่

Vercel รุ่นนี้จำกัดการ Login ผิดตาม username โดยไม่เชื่อค่า IP จากผู้เรียก

รุ่น Vercel นี้เพิ่มปุ่มพิมพ์ / บันทึก PDF และดาวน์โหลด CSV ในทุกหน้าข้อมูล CSV ตรงกับหน้าที่เปิดและตัวกรองปัจจุบัน เช่น เปรียบเทียบส่งออกสองปี, รายคณะส่งออกทุกปีของคณะที่เลือก และผู้ใช้ส่งออกเฉพาะชื่อ/บทบาท/สถานะ ไม่ส่ง password hash หรือ salt ส่วน PDF ใช้หน้าต่างพิมพ์ของ Browser → Save as PDF ไม่ใช่การสร้าง PDF โดย Server
