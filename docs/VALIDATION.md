# ผลการตรวจสอบ R-FUND Insight 1.0.0

วันที่จัดทำ: 3 ตุลาคม 2569

## ผ่านการตรวจสอบ

`npm test` ผ่าน **15 tests** ไม่มีข้อผิดพลาด

- setup สร้างข้อมูลจาก Excel 28 รายการ และรันซ้ำไม่เพิ่มข้อมูลซ้ำ
- ยอดรวมปี 2567 = 25,341,497.63 บาท และปี 2568 = 51,386,071.33 บาท; FTE = 456 และ 437 ตามลำดับ
- Teacher เพิ่มและแก้ไขทุนได้ ถูกปฏิเสธเมื่อสั่งลบ กู้คืน จัดการผู้ใช้ คณะ หรือเกณฑ์
- Owner อ่านได้ แต่คำสั่งเขียนถูกปฏิเสธ; Admin ลบและกู้คืนทุนได้
- ป้องกันคณะ–ปีซ้ำ ตรวจค่าติดลบ FTE ศูนย์ คะแนนเกิน 5 และ revision ที่เก่าแล้ว
- คะแนน AUTO ต้องมีเกณฑ์ และเปลี่ยนเกณฑ์แล้วคำนวณใหม่เฉพาะ AUTO
- ไม่ส่ง password hash/salt ให้ Browser และปิดเซสชันเมื่อเปลี่ยนรหัสหรือปิดบัญชี
- ปฏิเสธ shared secret ผิด เซสชันหมดอายุ และจำกัดจำนวนครั้งของ Login ผิด
- ข้อความที่เหมือนสูตร Sheet ถูกบันทึกเป็นข้อความ
- Proxy ตรวจ Origin และไม่เชื่อ token, secret หรือ IP ที่ Browser ส่งเอง
- Token ถูกซ่อนใน HttpOnly / Secure cookie ไม่อยู่ใน JSON ที่ส่งให้ Browser
- Network timeout ไม่มีการ retry คำสั่งเขียนอัตโนมัติ
- ตรวจ HTML ที่โค้ดสร้าง: Teacher มีเพิ่มและแก้ไข ไม่มีลบ; Owner ไม่มีปุ่มเขียน; Admin มีเมนูบริหาร
- ทุกหน้าเรียกสร้าง HTML จากข้อมูลจริงที่แนบได้ ไม่มีค่า undefined/NaN และหน้า Admin ถูกกันจาก Teacher
- ตัวกรองทุกปีถูกคงไว้หลังโหลดข้อมูลใหม่

`npm run build` ผ่าน: สร้างไฟล์เว็บใน `dist/` และไม่มี `demo-data.json` ในไฟล์ Production

ตรวจไฟล์ Excel จากฟังก์ชันส่งออกของเว็บ: เป็น ZIP / OOXML ที่ถูกต้อง เปิดด้วย openpyxl แบบอ่านอย่างเดียวได้ มี 28 แถวข้อมูลและ 9 คอลัมน์ เก็บภาษาไทยและ FTE ทศนิยมเป็นค่าที่ถูกต้อง และยอดรวมทั้งสองปีตรงต้นฉบับ

ตรวจ syntax JavaScript ของหน้าเว็บ ตัวกลาง Cloudflare และไฟล์ตัวอย่าง HTML แบบ standalone แล้ว

## ยังไม่ได้ยืนยัน

- **ยังไม่ได้ทดสอบกับ Google Sheet สด**: ไม่มี Apps Script Web App URL ที่เผยแพร่แล้วหรือการเข้าถึงบัญชีของผู้ใช้ การทดสอบ Backend ใช้บริการ Google Sheets จำลองในเครื่อง ไม่ใช่การเรียกบริการ Google จริง
- **ยังไม่ได้ทดสอบ Deploy บนบัญชี Cloudflare ของผู้ใช้**: ต้องตั้ง Environment Variables และเผยแพร่ตามคู่มือติดตั้งก่อน
- **ยังไม่ได้ตรวจภาพหน้าจอและ UI interactions ใน Browser จริง**: ไม่มี Chromium ที่ติดตั้งในเครื่องทดสอบ การดาวน์โหลด Chromium ไม่ได้ไฟล์ที่ใช้งานได้ และ Cloud Browser เปิด localhost ของเครื่องทดสอบไม่ได้ จึงไม่ได้อ้างว่าผ่าน visual QA หรือ Playwright UI smoke
- Responsive CSS รองรับหลายขนาด แต่ยังต้องเปิดตรวจการจัดวางจริงบนอุปกรณ์
- คะแนนประเมินจาก Excel ถูกรักษาไว้ แต่เกณฑ์ที่หน่วยงานใช้อย่างเป็นทางการยังไม่ได้รับ จึงไม่กำหนดเกณฑ์ AUTO เริ่มต้น
- Google Sheet ปัจจุบันอาจเปลี่ยนจากไฟล์ Excel แนบ ต้องตรวจยอดก่อนเปิดใช้งานจริง

มี `tests/ui-smoke.mjs` สำหรับรันเมื่อมี Playwright / Chromium และ preview server พร้อม: ตรวจเมนู ทุกบทบาท Popup ส่งออก และหน้าจอ desktop/mobile

## ข้อจำกัดที่ควรทราบในการใช้งาน

- ข้อมูลคำนวณที่บันทึกใน Sheet เป็นค่าจาก Server ไม่มี onEdit trigger ให้แก้ผ่านเว็บเป็นหลัก
- AuditLog แสดง 500 รายการล่าสุดในหน้าเว็บ ส่วนประวัติทั้งหมดเก็บอยู่ใน Sheet
- Soft delete ใช้กับข้อมูลเงินทุน; คณะและผู้ใช้ใช้การปิดใช้งานเพื่อคงประวัติ
- ระบบอ่านทั้งตาราง เหมาะกับขนาดข้อมูลปัจจุบัน หากขยายมากควรทบทวนเวลาอ่าน Sheet และ quota ตามบัญชีที่ใช้
- Login ใหม่ของ username เดียวกันยกเลิกเซสชันเก่า ควรสร้างบัญชีส่วนตัวสำหรับผู้ใช้แต่ละคน
- พิมพ์ PDF ผ่าน Browser; Excel ส่งออกเป็น `.xlsx` จริง
- ScriptLock ป้องกันการเขียนพร้อมกัน แต่ Google Sheets ไม่รองรับ transaction หลายชีต การขัดข้องกลางทางต้องตรวจข้อมูลจริงก่อนบันทึกซ้ำ
- ไฟล์ `R-FUND-Insight-Preview.html` เป็นตัวอย่างอ่านอย่างเดียวจาก Excel; ไม่เชื่อม Sheet และไม่ได้ใช้แทนไฟล์ Deploy
